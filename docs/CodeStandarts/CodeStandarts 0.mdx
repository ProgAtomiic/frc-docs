# Nomeclatura

OBJETIVO:  
Este documento foi feito visando padronizar o nome de variáveis, constantes, métodos e arquivos  do código.

NOME DE CÓDIGO:
ROBÔ_ANO_TEMPORADA_TORNEIO.
VARIÁVEIS:
Ex: Motor esquerdo → leftMotor
Ex2: Velocidade motor esquerdo → leftMotorSpeed
Ex3: Colocar motor esquerdo numa posição → setLeftMotorPosition
Ex4: Pegar posição do motor esquerdo → getLeftMotorPosition
CONSTANTES:
Ex: Id do motor esquerdo → kLeftMotorID

Além da formatação, é importante usar nomenclaturas que representam sua função de forma direta, fazendo com que a compreensão do código seja mais rápida.

# CONFIGURAÇÃO WPILIB VS CODE:

:::note
Este documento foi feito visando introduzir a configuração do ambiente de programação da FRC.
:::

### COMO BAIXAR E INSTALAR O WPILIB VS CODE:

1. Acesse o site oficial de documentação e downloads da **WPILib Installation Guide**.

2. Baixe o instalador oficial para o seu sistema operacional (Windows, macOS ou Linux) na seção de ativos do **WPILib Releases** no GitHub:
 
3. Execute o arquivo baixado e clique em **Start**:


4. Escolha a opção **Everything**, e selecione **Install for all Users**:


5. Agora, selecione **Download for this computer only (fastest)** e aguarde a conclusão do processo:


---

### COMO CRIAR UM PROJETO:

1. Com o WPILib VS Code aberto, selecione o ícone no canto superior direito:


2. Selecione a opção **WPILib: Create a new project**:


3. Escolha o tipo de projeto, linguagem (**Java**) e modelo do projeto nos 3 quadrados superiores (`example`, `java`, `Getting Started`).

4. Agora, selecione a pasta em que o arquivo ficará, o nome do projeto e o número da equipe:


5. Agora selecione **Generate Project**:
